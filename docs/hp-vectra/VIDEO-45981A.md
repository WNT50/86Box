# HP 45981A Multi-Mode Video Adapter —— 86Box 实现进度

**文件**：`src/video/vid_hp45981a.c`（CGA 派生卡，复用 `vid_cga.c` 的 CRTC / 渲染 / 时序核心）
**设备名**：`hp45981a`（配置项 `gfxcard = hp45981a`）
**状态**：步骤 1（端口面）+ 步骤 2（32 KB 显存 / 8 页）已完成并跑通整机；步骤 3（400 线）未做。

---

## 1. 已实现的端口面

| 端口 | 方向 | 含义 | 由谁处理 |
|---|---|---|---|
| `3D0`/`3D2`/`3D4`/`3D6` | 写 | MC6845 索引寄存器（四处镜像） | `cga_out()`（内部 `addr & 0xFF9 \| 4` 归一） |
| `3D1`/`3D3`/`3D5`/`3D7` | 读写 | MC6845 数据寄存器（四处镜像） | `cga_out()` / `cga_in()` |
| `3D8` | 写 | 模式控制（6 位，同 CGA） | `cga_out()` |
| `3D9` | 写 | 颜色选择 | `cga_out()` |
| `3DA` | 读 | 状态（回扫 / 垂直同步） | `cga_in()` |
| `3DB`/`3DC` | 读 | 光笔锁存 | `cga_in()`（本卡不使用） |
| **`3DE`** | **写** | **扩展控制寄存器（6 位）** | `hp45981a_set_ext_ctrl()` |
| `3DF` | 读 | 本卡未用，返回 `0xFF` | 本地 |

`3DE` 位定义（手册第 7 章）：

| 位 | 含义 | 实现 |
|---|---|---|
| 0 | `0` = 200 线，`1` = 400 线 | 只锁存，**未参与时序**（步骤 3） |
| 1 | 下划线使能 | 只锁存（属性渲染未实现） |
| 2 | 字体 `0` = 标准，`1` = HP Roman-8 | **切换 `cga.font16`** |
| 3 | 显存禁止响应 | **CPU 读写一律丢弃 / 返回 `0xFF`** → 屏幕空白 |
| 4 | `0` = 16K 地址空间，`1` = 32K | **切换 `cga.vram_mask`（0x3FFF / 0x7FFF）** |
| 5 | 页选择（仅图形模式） | 只锁存（图形翻页未用） |

## 2. 显存

- 32 KB，映射 `B8000–BFFFF`，通过 `hp45981a_read/write` 包一层再交给 `cga_write/read`。
- **16K 模式**：地址按 `& 0x3FFF` 回绕，CPU 只看到前 16 KB（手册 Table 7.6「前 16K 可用、32K 内回绕」）。
- **32K 模式**：`& 0x7FFF`，整块可见。
- **字符模式翻页靠 6845 起始地址**（R12/R13），不靠 `3DE` bit5：80×25 一页 2000 字 = 4000 字节，八页正好填满 32 KB。渲染路径直接沿用 CGA 的 `memaddr`，因此翻页是免费的。

为支持 32 KB，`vid_cga.c` 里原先写死的 `DEVICE_VRAM_MASK` 改成 `cga_t.vram_mask`（新增字段），并加了 `cga_vram_mask()` 兜底：NCR、Olivetti OGC、PC1512 等不调用 `cga_init()` 的派生卡仍按 0x3FFF 走，行为不变。

## 3. 字符 ROM

- 卡在初始化时尝试加载 `roms/machines/hpvectra/45981a_chargen.bin`（4096 字节，256 字符 × 16 行）。
- 加载成功才允许 `3DE` bit2 切到 HP 字体；文件缺失则始终用 IBM CGA 字体（不报错，不影响启动）。
- 200 线文本模式下用该字模的**第 1–8 行**（`cga_glyph_row()`，注释在函数上）。
- ⚠️ 该文件目前是**替身**：由 HP 9836A chargen（`hp9836a_chargen.bin`）改名而来，不是 45981A 原卡 ROM 的 dump（原卡 ROM 至今无公开镜像）。详见 `fonts/README.md`。

## 4. 验证记录（2026-10-31）

| 项 | 结果 |
|---|---|
| `gfxcard = hp45981a` 冷启动 | **22 s 直达 `A>`**，PAM 主菜单正常 |
| `gfxcard = cga`（回归） | **22 s 直达 `A>`**，`needed F1 / config error: False` |
| 端口写入计数（一次冷启动） | **4966 次**，全部落在 `3D4`/`3D5`/`3D8`/`3D9` |
| 启动期 `3DE` 写入 | **0 次**（与早先对 ROM/DOS 的静态扫描一致：BIOS 从不碰 `3DE`） |
| `HP45981A_EXT=04`（HP 字体） | 22 s 到 `A>`；与标准字体逐像素比较 **7450 / 128000 像素不同**，PAM 边框制表符按 Roman-8 映射成字母/符号 |
| `HP45981A_EXT=14`（32K + HP 字体） | 22 s 到 `A>` |
| `HP45981A_EXT=1C`（32K + 字体 + **显存关闭**） | **60 s 内无 `A>`**，屏幕空白 —— 证实 bit3 生效 |

## 6. 尚未实现

1. **400 线（`3DE` bit0）**：需要主振 22.440 MHz / 25 kHz 行频、8×16 字符单元、`dispontime` 与 `dispofftime` 按 CRTC 重算，以及活动行 400（现 CGA 核心固定在 200 线、`displine < 360`）。估 200 行。
2. **图形页选择（`3DE` bit5）**。
3. **下划线属性（`3DE` bit1）**：前景色 `001` 的字符加下划线并强制 `111`。
4. **原卡字符 ROM**：无公开 dump，现用 HP 9836A 字模顶替。
