# HP Vectra 45945A — HP-HIL 与 POST 卡点地图

本文件汇总 `F000` ROM 里 HIL/8041 相关代码的反汇编结论，以及 86Box 侧
`vectra` 分支目前的实现状态。所有地址都是 ROM 内的 16 位偏移（段 `F000`）。

## 1. 端口

| 端口 | 方向 | 语义 |
|---|---|---|
| `0x60` / `0x64` | R/W | 8041（键盘控制器）数据/状态，AT 兼容 |
| `0x68` | W/R | 8041 命令/数据（写：`0x86DA`；读：回环到 `0x60`） |
| `0x69` | R | 8041 状态/命令完成码（`0x06` = `0x60` 命令执行完） |
| `0x6A` | W | 8041 选通 |
| `0x6C` | R/W | HIL 帧数据（W0 写即发一帧；R0 读并弹 FIFO） |
| `0x6D` | R/W | HIL 命令位+地址（W1）；R1 窥视队首，bit4 = 发送忙 |
| `0x6E` | R/W | R2 错误寄存器（只读）；写 `0xFE` = 复位适配器 |
| `0x6F` | R | R3：bit0 = INT（有帧待取）；读 **不**清 INT |
| `0x7C` / `0x7D` | W | 第三片 8259（IRQ16–23） |
| `0x20` / `0x21` | W | 主片 8259 |

## 2. 中断

主片 IR1 ← 第三片输出（`pic_attach_slave(&pic3, 1)`）。
第三片：line0 = IRQ16 SVC-8041，line1 = IRQ17 OBF-8041，line4 = IRQ20 HPHIL（向量 `6Ch`）。

ISR `F000:552D`（IRQ20）：

```
552D  pusha
5530  cx=0x114  dh=0x10  dl=0x64        ; 记录号 / IRQ20 位 / 特定 EOI 值
553C  ds = [[0:0x1BC+2] 段的 [0x12+4]]  ; → 9F8D
554A  test byte [0x40],1 / jnz          ; 重入保护
5559  ss:[0x6], sp:[0x4]                ; 切专用栈
557E  in 0x7D / or al,0x10 / out 0x7D   ; 屏蔽 IRQ20
5588  out 0x20,0x20                     ; 主片非专用 EOI
5593  int 6F  (AH=0, BP=0x114)          ; → F000:87D0，DS=9F8D
559E  in 0x7D / and al,~0x10 / out 0x7D ; 解除屏蔽
55A4  out 0x7C,0x64                     ; 第三片特定 EOI，L2=4
```

### 三条中断入口（IVT 实测）

| 向量 | 入口 | 参数 | 去向 |
|---|---|---|---|
| `68h` IRQ16 SVC | `F000:551F` | `cx=0xAE dh=0x01 dl=0x60 bh=4 bl=0` | 共用体内 `int 6F AH=4`（BP=`0xAE`）→ `0x8190` → `0x82F3` 状态分派 |
| `69h` IRQ17 OBF | `F000:5514` | — | `out 0x7C,0x61`（pic3 EOI L2=1）→ `int 9`（键盘 BIOS） |
| `6Ch` IRQ20 HPHIL | `F000:552D` | `cx=0x114 dh=0x10 dl=0x64 bh=0 bl=0` | `int 6F AH=0`（BP=`0x114`）→ `0x87D0` 设备服务 |

共用体在 `0x5537`：`push ds; xor ax,ax; mov ds,ax; mov bp,0x1BC; mov ds,[ds:bp+2];
mov bp,0x12; mov ds,[ds:bp+4]` —— 经 `[0:0x1BC]`（IVT `6Fh` 段）→ `9F00` 的记录表取 DS，
随后按 `dh`/`dl` 做「屏蔽 → 主片 EOI → `int 6F` → 解除屏蔽 → 第三片特定 EOI」。

实测：给 `0x68` 写入命令字节后拉 OBF（line 1），`INTA ret=69` 出现 2 次，
说明 IRQ17 通路可用；但 HIL 状态机不动，仍缺 SVC 侧的事件语义。

## 3. 设备服务 `F000:87D0`（`int 6F AH=0 BP=0x114`）

`9F00:0114` 记录 → `F000:87D0`，DS=`9F8D`。`AH` 经表 `0x87E7` 分派，`AH=0` → `0x8860`：

```
8860  es = ds
886B  test word [0x10],0x1000        ; bit12 = 已初始化
8873  int 6F AH=4 AL=8               ; 0x8444: 往 0x68 写 0xFB（系统硬复位）
887E  int 6F AH=0x0C via [0x0C]      ; 设备表操作
8888  cmp ah,0 / cmp ah,8 / 否则 or [0x10],0x8   ; bit3 = 出错
8898  bl = [0x13]; call [cs:bx+0x88C5]           ; 状态分派
88A3  and word [0x10],0xEFF7         ; 清 bit12 + bit3
88A9  int 6F AH=4 AL=[cs:bx+0x88C2]  ; 06 / 04 / 02
```

### 置 bit2（POST 放行）的路径

```
状态 1A  0x8E2A: 依赖 [0x12] bit7 与 [ds:bp+0x1D] ?= [0x19]
         → 0x8E79/0x8E7F: [0x13] = 0x12
状态 12  0x8E94: or word [0x10],0x1000 ; jmp 0x8860
         → 重入后 886B 走"已初始化"分支 → 状态 04
状态 04  0x892B → 0x894A → 0x8956: or word [0x10],0x4   ← 置 bit2
```

## 4. `int 6F AH=4` 子功能（`0x82B1`，表 `0x82C3`，按 AL 字节索引）

| AL | 目标 | 动作 |
|---:|---|---|
| `06` | `0x8438` | `bl=0xFE` → `0x86DA`，写 `0x68`（DHR） |
| `08` | `0x8444` | `bl=0xFB` → `0x86DA`（系统硬复位） |
| `0A` | `0x844C` | `0x86C0` 查设备表，找到则 `[ds:bp+0x13]=bh` |
| `0C` | `0x845D` | 查表，找到则清该设备位（`and [0x11],~bl`） |
| `0E` | `0x8471` | 查表，找到则置位（`or [0x11],bl`）、首次时发 `0xF8`、`inc [0x12]` |

`0x86C0`：在 `[ds:0x13]` 起 8 字节设备表里查 `bh`，返回 `bl` = 位掩码，`ah=0` 或 `0xFE`（未找到）。
`0x86DA`：等 `0x64` IBF 空，然后 `out 0x68, bl`。
`0x86E7`：`int 6F`（`BP=[0x0C]`）。

## 5. 8041 状态分派 `0x82F3`

`int 6F AH=4 AL=0` → `0x82F3`：

```
82F3  in al,0x69            ; 状态字节覆盖 AL
82F5  test al,0x20 / jz     ; bit5 → 0x8363（设备事件转发，int 6F AH=4 AL=0x18）
82FC  test al,0x10 / jz
8303  and al,0x0f / shl ax,1
8311  jmp [cs:bp+0x8319]    ; 12 项表
8316  out 0x6a,al / iret
```

| idx | 目标 | 动作 |
|---:|---|---|
| 0/4/5 | `0x8316` | 空 |
| 1 | `0x8371` | `[0x10] = ([0x10]&1) \| 0xF5` |
| 2 | `0x8389` | `int 6F AH=2 AL=0x12` |
| 3 | `0x839A` | 遍历 `[0x11]`，每设备 `int 6F AH=2 AL=0x14` |
| 6 | `0x83C3` | 清 bit2 |
| 7 | `0x83CA` | 置 bit2（DS=9FAE，与 POST 等的 9F8D 不是同一块） |
| 8 | `0x83F5` | 8041 字节泵（读 `0x69`，`0x78–0x7E`/`0xF8–0xFE` 当键码） |
| 9 | `0x83D6` | 清 bit3 + `int 6F AH=4 AL=0x16, dl=0x44` |
| A | `0x83D1` | 清 bit3 |
| B | `0x8428` | 清 bit3 |

## 6. HIL 帧通道

- 发送 `0x7B85`：等 `0x6D` bit4 清零 → `out 0x6D`（DH）→ `out 0x6C`（DL）；AH=0 正常 / FE 超时 / 2,3 错误；**发完不等回**。
- 接收 `0x7DDC`：轮询 `0x6F` **直到恰好等于 1**（最多 65536×80 次），再读 R1(`0x6D`)、R0(`0x6C`)，返回 `(R0<<8)|R1`；超时返回 0。
- 取一帧 `0x7BAE`：`0x6F` bit2（LERR）→ AH=3；`0x6E`≠0 → AH=2；否则 R1→BH、R0→BL。
- 回环自检 `0x7D65`：四段「写 0x6D/0x6C → 读回 → `cmp ax,bx`」，错误位累积在 CL（bit0/1/2/4），结束写 `0x6E,0xFE`。包装 `0x7D3C` 在 CL≠0 时返回 AH=0xFE、BX=0x3000|CL。
- 上下文初始化 `0x7CBE`：清 32 字节 → 从 ROM `0x7B50` 拷 16 字节模板（`00 84 08 00 30 00 00 00 00 00 14 01 06 00 00 00`）→ `[0x11] &= AL` → `[0x10] &= ~4` → 跑自检。
- 枚举 `0x7D0A`：循环 16 次 `0x7BAE`，把 BL/BH 收进 ES:DI；入口 `0x7465` 要求 `[0x10]` bit12 置位。

## 7. 8041 诊断（键盘路径，全部通过）

```
1DC2  in 0x60 / cmp al,0x55      ; AA 应答
1DCC  out 0x6A,al
1DD1  in 0x69 / or al,al / loopne
1DD8  out 0x6A,al
1DDE  ah=0x60 → 0x64 ; ah=0x45 → 0x60
1DFD  in 0x69 / cmp al,0x6      ; 必须等于 0x06
1E1B  ah=0x69 → 0x68 ; 等 OBF ; in 0x60 必须读回 0x69
```

## 8. 86Box 侧已修 / 未解

已修（提交）：

- `fc4573b75` 第三片 8259 的 IRR 改成**边沿锁存**（原来线一落就抹掉请求，导致 IRQ20 永远送不到 CPU）。修后 `INTA ret=6C`、ISR `552D`、服务 `87D0` 两次全部跑通。
- `a4149b010` 设备层离开回环（EPT）、POL 回报告记录。
- `68fb9e679` HIL 链路只带鼠标（ID `68h`，HP Mouse 46060A）。
- `5f7798f34` INT 跟随 FIFO（电平），读 R3 不再清。
- `7f646ada9` / `1c372f428` / `7d7e95772` / `f27168cfd` `EPOCH_HIL_BP` 探针（env 门控，过卡点后删）。

未解：

- POST 停在 `F000:92AB`，等 `9F8D:0010` 的 bit2；状态机只到 `00/02`，走不到 `1A → 12 → 04`。
- ROM 全程只发回环自检帧和一次 DHR，**没有 EPT / ACF / IDD / POL**，设备层用不上。
- 服务里的 `int 6F AH=4 AL=8` 只往 `0x68` 写 `0xFB`；8041 之后该回什么、谁把状态推到 `1A`，仍未确定。
- 运行时 `9F8D:[0x0A]=0x002A`、`[0x0C]=0x0030`，而 `9F8D:0x30` 处记录全零 —— 说明 HIL 上下文尚未初始化（与服务里 `[0x0C]` 记录被调用相矛盾，需再核）。
